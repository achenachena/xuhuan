# Fan reference and source policy

## Scope

Xuhuan is an unofficial, non-commercial fan project and engineering portfolio demonstration. Its V4 plot, dialogue, aftershow incidents, enemies, bosses, and jokes are original fiction about digital personas. They are not biographies and do not claim that the depicted events happened to a real performer or organization.

The links below are public profile anchors used only to identify the intended public-facing character reference and spelling. V4 does not copy dialogue, lyrics, private anecdotes, rumors, or a video's narrative from these pages. No chapter currently depends on an external joke or quoted performance.

## Rules for future references

1. Prefer original fictional situations that only need a public character identity anchor.
2. If a specific public joke is essential, cite the exact official/public video page in this document before merging the content.
3. Describe the reference in original words. Do not reproduce lyrics or long quotations; any short quotation must stay within applicable copyright limits.
4. Never use private information, leaked material, gossip, health or relationship claims, inferred identity details, or content from unofficial reuploads as narrative fact.
5. Do not imply endorsement, affiliation, or cooperation.
6. Keep visual and audio provenance review separate from story-reference review. A public profile link does not grant redistribution rights to an image, recording, or model.
7. Remove a disputed reference promptly while preserving the original gameplay behavior with neutral fictional copy.

If a safe primary source cannot be verified, record that the chapter uses no external reference. Never invent a citation to make a joke appear sourced.
