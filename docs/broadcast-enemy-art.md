# Broadcast enemy art

Six original AI-generated pixel illustrations made with OpenAI image generation for the broadcast-themed enemies. Existing character fan-art provenance remains unchanged. PNG originals are outside the repository; runtime WebP files retain transparency and use nearest-neighbor downsampling.
