# Livestream stage backgrounds

Eight AI-generated backgrounds replace the generic city corridors. Each room relates to the character’s fictional broadcast: waterfront studio, idol stage, clip room, dance rehearsal, recording booth, mirrored rehearsal, botanical studio, ensemble stage.

Generated with the built-in imagegen tool, then resized and encoded as 576 × 1024 WebP. These are static cached backdrops, not new per-frame effects. Detail stays around the perimeter so enemies and bullets remain readable. New `-stage.webp` URLs invalidate the immutable asset cache; the replaced files are removed. Old URLs redirect to the replacements because persisted Telegram segments contain those paths. Existing character sprites and fan-project licensing status are unchanged.
